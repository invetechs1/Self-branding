# مقاطع شرح النظام

مقاطع مسجّلة تشرح النظام وتعرض تشغيله. الصوت غير موجود — النصّ كله على الشاشة.

| المقطع | المدة | ماذا يعرض |
|---|---|---|
| `06-seven-improvements.mp4` | ٣:٢٢ | جولة التحسينات السبعة: المشكلة ← ما بُني ← النتيجة لكل تحسين، والأخطاء التي أمسكتها الاختبارات، وما ينتظر تعبئتك |

## كيف صُنعت

ليست تسجيل شاشة. الصفحة تُبنى بـ HTML ثم تُسجَّل عبر Chromium بلا واجهة، فالنص حادّ
والمحتوى قابل للتحديث:

```
صفحة HTML (مشاهد متتابعة) → تسجيل Playwright (webm) → ترميز ffmpeg (mp4)
```

سكربتات التوليد ليست في المستودع لأنها أدوات جلسة لا جزء من النظام. اطلبها متى أردت
إعادة توليد مقطع بعد تغيير المحتوى.

## حدود ما تعرضه المقاطع

المقاطع التي تُظهر **تشغيلاً فعلياً** (الاكتشاف، الاختبارات، النشر) حقيقية المخرجات،
باستثناء شيئين موسومين فيها صراحةً:

- **مصادر الأخبار:** ملفات اختبار ثابتة تُقدَّم عبر خادم محلي، لأن شبكة بيئة التطوير
  تحجب مواقع الأخبار.
- **استدعاء النموذج:** مستبدَل — لا مفتاح Anthropic في بيئة التطوير.

ما عدا ذلك كود حقيقي: الجلب والترتيب والتجميع والتصنيف وبوابة الاعتماد والتعلّم.
المقاطع التي تعرض **شكل المنشور على المنصات** معاينات مصمَّمة، لا لقطات من حساب حقيقي —
ولم يُنشر شيء على أي حساب.
