# لوحة القياس — المراجعة الأسبوعية والشهرية

القياس هو ما يحوّل النشر من عادة إلى نظام يتحسن. 20 دقيقة كل جمعة، وساعة نهاية كل شهر.

## المراجعة الأسبوعية (كل جمعة — 20 دقيقة)

انسخ الجدول لأسفل الملف وعبّئه من إحصائيات المنصات:

```markdown
### الأسبوع المنتهي في: YYYY-MM-DD

| المنصة | متابعون (±) | أفضل منشور | مشاهدات/وصول | حفظ/مشاركة |
|--------|------------|------------|---------------|-------------|
| X | | | | |
| انستقرام | | | | |
| تيك توك | | | | |
| لينكدإن | | | | |

- الالتزام بالإيقاع: نشرت X/Y منشوراً مخططاً
- أفضل محتوى ولماذا نجح (الخطّاف؟ الموضوع؟ التوقيت؟):
- أسوأ محتوى ولماذا:
- فرص واردة هذا الأسبوع (رسائل، دعوات، عملاء):
- قرار واحد للأسبوع القادم:
```

## المراجعة الشهرية (إضافة على الأسبوعية)

- **SEO (من Search Console):** صفحات مفهرسة، استعلامات الظهور، نقرات بحث الاسم.
- **القائمة البريدية:** مشتركون جدد، معدل الفتح.
- **العلاقات الإعلامية:** رسائل مرسلة / ردود / ظهورات (من `outreach/targets.csv`).
- **قرار التوزيع:** أي عمود محتوى يأخذ حصة أكبر الشهر القادم؟ (اتبع البيانات لا الذوق).

## إشارات القيمة الحقيقية (رتّبها فوق عدد المتابعين دائماً)

1. **الفرص الواردة** — استشارة، دعوة، عرض شراكة: المؤشر الأول للنجاح.
2. **الحفظ (Bookmarks/Saves)** — محتواك مرجع، وهذا ما تكافئه الخوارزميات.
3. **الردود النوعية** — أسئلة حقيقية من جمهورك = مواضيع محتواك القادم.
4. عدد المتابعين — مهم، لكنه نتيجة للثلاثة أعلاه وليس هدفاً بذاته.

## إنذارات مبكرة

- 3 أسابيع متتالية بلا نمو → المشكلة في الخطّافات غالباً: جرّب 5 صيغ افتتاح جديدة.
- وصول عالٍ وتحويل ضعيف للمتابعة → المشكلة في النبذة (Bio) أو اتساق المحتوى.
- تفاعل من غير جمهورك المستهدف → راجع المواضيع؛ الانتشار الخاطئ يضر الاستهداف.
