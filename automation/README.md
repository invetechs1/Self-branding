# الأتمتة — محرك الاستخبارات وتوليد المحتوى والنشر

## كيف يعمل النظام

```
  المصادر (sources.yml)              profile/persona.yml + facts.yml
        │                                      │
        ▼                                      ▼
  news_engine.py --discover  ←─── الأوزان والعتبات وخريطة الاهتمامات
        │  جمع → استبعاد غير ذي الصلة → تجميع المكرر → مصداقية → ملاءمة → ثقة الحقائق
        ▼
  queue/news.jsonl  (قصص مرتّبة 0-100 + فرص أعمال مرصودة)
        │
        ▼
  generate_posts.py --from-news        (أو --week من بنك الأفكار)
        │  زاوية واحدة → طبقة رؤية يحيى → نسخة لكل منصة → فحص سلامة (أخضر/أصفر/أحمر)
        ▼
  queue/queue.csv  (status=draft)
        │
        ▼  مراجعتك: draft → approved  (أو rejected — وهي إشارة تعلّم)
        │
  publish.py  ← كل ساعة عبر GitHub Actions — ينشر المستحق فقط
        ▼
  X / LinkedIn / Instagram / TikTok / الموقع
        │
        ▼
  analytics/performance.csv → feedback.py --learn → learning/weights.yml
        └────────── يعيد ضبط ترتيب الأخبار القادمة (الأعمدة الناجحة ترتفع) ──────────┘
```

## الملفات

| الملف | الدور |
|---|---|
| `persona.py` | القلب: الترتيب، التجميع، ثقة الحقائق، مستويات الاعتماد، ذاكرة المحتوى، بناء تعليمات النموذج |
| `news_engine.py` | الاكتشاف والترتيب والتقرير الأسبوعي |
| `generate_posts.py` | تحويل الأخبار/الأفكار إلى مسودات موسومة بالكامل |
| `publish.py` | النشر المجدول ببوابة الاعتماد |
| `feedback.py` | التعلّم من الأداء ومن قرارات يحيى |
| `sources.yml` | مصادر الأخبار — سعودية عربية أولاً + جهات حكومية تُتابَع يدوياً |
| `calendar_sa.py` | رزنامة المناسبات السعودية: تنبّه قبل المناسبة بمهلة كافية |
| `gov_watch.py` | مرصد القرارات الحكومية: يقرأ صفحات الجهات التي لا تملك RSS |
| `data_stories.py` | حواجز السرية على أرقامك التشغيلية + تجهيزها للمحتوى |
| `fetch_metrics.py` | سحب مقاييس الأداء من المنصات إلى ملف الأداء |
| `gov_sources.yml` | الجهات الحكومية المرصودة ومحددات صفحاتها |
| `learning/weights.yml` | مضاعِفات الأعمدة — تُولَّد آلياً |
| `tiktok.py` | تكامل تيك توك: رفع الفيديو، تجديد الرموز، استخراج الكابشن |
| `tiktok_auth.py` | ربط حسابك على تيك توك (OAuth) وحفظ الرموز |
| `tests/run_tests.py` | اختبار شامل (199 فحصاً) للمسار كاملاً — بلا مفاتيح وبلا شبكة خارجية |

## التشغيل

```bash
pip install -r requirements.txt
cp config.example.yml config.yml     # وعبّئ المفاتيح — لا يُرفع إلى git أبداً

python tests/run_tests.py                     # الاختبار الشامل للنظام (199 فحصاً)
python persona.py --self-test                 # فحص سريع لمنطق الترتيب والسلامة
python news_engine.py --check-sources         # فحص روابط المصادر
python news_engine.py --discover              # دورة اكتشاف وترتيب (بلا مفاتيح كذلك)
python gov_watch.py --check                   # فحص صفحات الجهات الحكومية
python gov_watch.py --probe hrsd              # اقتراح محددات لجهة واحدة
python gov_watch.py --fetch                   # جلب القرارات الحكومية إلى السجل
python news_engine.py --top 10                # أهم القصص المخزّنة
python generate_posts.py --from-news          # مسودات من أهم الأخبار  (يحتاج مفتاح Anthropic)
python generate_posts.py --week               # أسبوع محتوى من بنك الأفكار
python publish.py --dry-run                   # ما الذي سيُنشر الآن؟
python generate_posts.py --occasions          # محتوى المناسبات التي حان وقتها
python data_stories.py --list                 # أرقامك التشغيلية وما ينقصها
python generate_posts.py --data-story         # محتوى من أرقامك (لا يُنشر دون مراجعتك)
python calendar_sa.py --days 60               # ما يقترب من مناسبات سعودية
python news_engine.py --report                # تقرير الاستخبارات الأسبوعي
python fetch_metrics.py                       # سحب مقاييس المنشورات من المنصات
python feedback.py --learn                    # تحديث أوزان التعلّم
```

`news_engine.py` و`persona.py` يعملان بلا أي مفاتيح — التوليد وحده يحتاج مفتاح Anthropic.

الاختبار الشامل يشغّل المسار الحقيقي كاملاً (جلب RSS من خادم محلي، ترتيب، تجميع، توليد، بوابة اعتماد،
نشر تجريبي، تعلّم، تقرير) ويستبدل استدعاء Claude API فقط. يُعاد تشغيله آلياً عند كل دفع إلى GitHub
عبر `.github/workflows/tests.yml`.

## صوتك الشخصي

`profile/voice-samples.md` هو ما يجعل المخرجات تشبهك لا تشبه أي كاتب. ضع فيه فقرات
**بقلمك أنت** (حتى رسائل واتساب عن مشكلة في مشروع)، فيقلّد النظام إيقاعك ومفرداتك
وطريقة فتحك وختمك — دون أن يقتبس وقائعها.

الملف الفارغ لا يضرّ: النظام يكتب بالقواعد العامة ولا يخترع صوتاً. وكل عيّنة تضيفها
تحسّن النتيجة فوراً بلا أي تعديل برمجي.

## المقاييس تُسحب آلياً

محرك التعلّم كان معلّقاً على تعبئتك اليدوية لـ `analytics/performance.csv` — أي أنه
كان سيموت بعد أسبوعين. الآن `fetch_metrics.py` يسحبها من المنصات:

| المنصة | ما تعطيه فعلاً |
|---|---|
| X | انطباعات · إعجابات · ردود · إعادة نشر واقتباس · حفظ (ونقرات وزيارات ملف إن سمحت صلاحيات تطبيقك) |
| تيك توك | مشاهدات · إعجابات · تعليقات · مشاركات |
| لينكدإن | إعجابات وتعليقات فقط — **الانطباعات غير متاحة** لمنشورات الحساب الشخصي عبر الواجهة |

انطباعات لينكدإن تجدها في «إحصاءات المنشور» داخل التطبيق. إن عبّأتها يدوياً فالسحب
الآلي **لا يمحوها**، ويُوسم الصف `api+manual`. وبدونها يتجاهل محرك التعلّم ذلك الصف
(لأن التفاعل نسبة إلى الانطباعات).

يعمل هذا تلقائياً قبل `feedback.py --learn` في دورة الاستخبارات الأسبوعية.

**شرط أساسي:** النشر صار يخزّن معرّف المنشور في عمود `external_id` — وبدونه يستحيل
القياس. ولثريد X يُخزَّن معرّف **رأس الثريد** لأنه ما يفتحه الناس.

## قصص البيانات — ما لا يستطيع منافس نسخه

منافسوك ينقلون الأخبار نفسها. الذي تملكه وحدك: ما تقيسه فعلاً في عزوم والعراب.
`profile/operations-metrics.yml` يحمل أرقاماً مجهّلة، و`data_stories.py` يفرض الحواجز
**برمجياً لا ثقةً**:

| الحاجز | ماذا يمنع |
|---|---|
| حد التجميع (٥ حالات) | رقم من حالة واحدة قد يكشف مشروعاً بعينه |
| وجوب الأساس | «٤٧ يوماً» ادعاء، و«٤٧ يوماً من ١٨ مستخلصاً» بيان |
| منع المبالغ المطلقة | نسب ومدد وأعداد فقط — لا ريالات ولا دولارات |
| `internal` / `never` | أرقام لا تخرج في منشور إطلاقاً |
| إلزام المراجعة | قصة البيانات لا تكون خضراء أبداً مهما بدا النص آمناً |

والتعليمات المرسلة للنموذج تمنعه من إضافة أي رقم غير المذكور، ومن ذكر أي عميل أو
مشروع، ومن تقديم رقمك كمعيار للقطاع.

**ابدأ بثلاثة أرقام تعرفها اليوم بلا بحث** — واحد منها يكفي لمنشور لا يستطيع أحد تقليده.

## مواعيد النشر تتعلّم من أدائك

المواعيد لم تعد مكتوبة في الكود. ترتيب الأولوية:

1. **موعد متعلَّم** من `analytics/performance.csv` — يُعتمد فقط إذا توفّر عدد كافٍ من
   المنشورات في الوقت نفسه لتلك المنصة (`posting.min_samples_per_slot`، الافتراضي ٣)
   **وكان داخل نافذة الاستراتيجية**
2. **افتراضي** من `profile/persona.yml ← posting.defaults`
3. احتياطي في الكود (لا يُستخدم عملياً)

النوافذ (`posting.windows`) تمنع التعلّم من إفساد الاستراتيجية: منشور واحد نجح الثالثة
فجراً لا يجعلها موعد نشرك. التعلّم يحسّن **داخل** النافذة الذهبية لا خارجها.

كل مسودة تحمل في `review_notes` مصدر موعدها، وأفضل أيام الأسبوع تظهر في تقرير التعلّم
**إرشادياً** لتعدّل الإيقاع بنفسك — لا تُطبَّق آلياً.

## مرصد القرارات الحكومية

أثمن مادة لجمهورك — ولا تملك أكثر الجهات تغذية RSS. لذلك `gov_watch.py` يقرأ صفحات
أخبارها مباشرة، بمستويين:

1. **محددات CSS صريحة** في `gov_sources.yml` (الأدق، وتقاوم تغيّر الموقع)
2. **استخراج تلقائي** حين لا توجد محددات: يجد أكبر مجموعة روابط متطابقة البنية
   ويرجّحها بكلمات الجهة، ويتجاهل روابط التنقل والتذييل

ثماني جهات مُعدّة مسبقاً، أولوياتها الثلاث الأولى: **الموارد البشرية، التأمينات،
هيئة المقاولين**. اضبط المحددات بعد `--probe` لكل جهة على جهازك.

خبر الجهة يُصنَّف تلقائياً مصدراً حكومياً رسمياً (مصداقية 100) وعموداً «قرارات حكومية»،
ويُعدّ سعودياً حتى لو خلا عنوانه من ذكر السعودية — لأن المصدر نفسه يحسم ذلك.

## التركيز السعودي

النظام مضبوط على ستة أنشطة سعودية (`profile/persona.yml ← saudi_activities`):

| النشاط | العمود | أمثلة ما يلتقطه |
|---|---|---|
| عالم المقاولات والمشاريع | `construction_projects` | ترسيات، مناقصات، مستخلصات، تصنيف المقاولين، تعثّر |
| عالم الذكاء الاصطناعي | `ai_technology` | نماذج، وكلاء، أتمتة، سدايا، رؤية حاسوبية |
| القرارات الحكومية والأنظمة | `government_decisions` | الموارد البشرية، التأمينات، التجارة، زاتكا، نطاقات، قوى |
| عامل البناء وأخطاء البناء | `site_quality` | سلامة المواقع، عيوب التنفيذ، كود البناء، مخالفات الأمانة |
| الترند في السعودية | `saudi_trends` | الأكثر بحثاً — يُعرض كإشارة لا كخبر |
| المناسبات الرسمية | `occasions` | اليوم الوطني، التأسيس، رمضان والعيدان، يوم العلم |

**سياسة «السعودية أولاً»** (`saudi_first` في persona.yml) تُطبَّق بعد حساب الدرجة:

- خبر سعودي داخل أنشطتك: يُرفع ×1.15
- خبر عالمي داخل أنشطتك: ×0.75 ويُوسم «اربطه بالسوق السعودي» — فلا يُنشر نقلاً
- ذكاء اصطناعي عالمي: ×0.8 (يبقى مطلوباً لأنه أحد أنشطتك)
- خبر عالمي خارج أنشطتك: ×0.45 — يسقط عملياً
- المصادر العربية تُفضَّل ×1.08

ولتقصر الاكتشاف على أنشطتك الستة حصراً، اضبط `require_activity_match: true`.

**المطابقة العربية** تتسامح مع السوابق واللواحق: «بالرياض» تُطابق «الرياض»، و«للمقاولين» تُطابق
«مقاول» — وهذا كان أكثر ما يُفقد الأخبار السعودية قبل الضبط.

**المناسبات:** `content/saudi-calendar.yml` يحمل المناسبات وزواياها ومهلة التنبيه. المناسبات
الهجرية (رمضان والعيدان) تُحسب بتقويم أم القرى عبر `hijridate`. القاعدة: لا تهنئة عامة — المناسبة
مدخل لمحتوى يفيد المقاول.

## بوابة الاعتماد (§37 من المواصفة)

| المستوى | متى يُمنح | شرط النشر |
|---|---|---|
| **أخضر** | معلومة عامة موثّقة أو محتوى تعليمي، بلا رأي أو ادعاء شخصي | `approved`، أو آلياً فقط إذا `auto_publish_green: true` و`require_approval: false` |
| **أصفر** | رأي أو توقع أو تعليق تجاري، أو ثقة حقائق دون 0.8، أو تشابه مع منشور سابق | `approved` بشرياً |
| **أحمر** | مصطلحات مالية/قانونية/سياسية/شخصية، ادعاء تجربة غير موثّقة، ثقة حقائق دون 0.6 | `approved` بشري صريح — لا نشر آلي إطلاقاً |

## ربط تيك توك

تيك توك لا ينشر نصاً — ينشر **فيديو**. لذلك صف تيك توك في الطابور يحتاج شيئين:
السكربت في `content` (للتصوير)، ومسار ملف الفيديو في `media_path` (للرفع). الكابشن يُستخرج
تلقائياً من سطر يبدأ بـ «الكابشن:» في السكربت، أو من عمود `caption`.

**خطوات الربط (مرة واحدة):**

1. على [developers.tiktok.com](https://developers.tiktok.com) أنشئ تطبيقاً واطلب منتج **Content Posting API**.
2. فعّل الصلاحيات: `user.info.basic` + `video.upload` (أضف `video.publish` إن أردت النشر المباشر لاحقاً).
3. سجّل **Redirect URI**: `http://127.0.0.1:8721/callback` (أو أي رابط تضعه في `config.yml`).
4. انسخ `client_key` و `client_secret` إلى `automation/config.yml`.
5. اربط حسابك:
   ```bash
   python automation/tiktok_auth.py --server   # يفتح رابط التفويض ويلتقط الرمز تلقائياً
   python automation/tiktok_auth.py            # أو الوضع اليدوي: الصق رابط العودة
   python automation/tiktok_auth.py --check    # تأكيد: يعرض اسم الحساب وقيوده
   ```

**وضعان للنشر (`mode` في `config.yml`):**

| الوضع | ماذا يحدث | المتطلبات |
|---|---|---|
| `inbox` (الافتراضي) | الفيديو يصل إلى **مسودات تطبيقك**، تراجعه وتنشره بنفسك | `video.upload` فقط — بلا تدقيق |
| `direct` | نشر مباشر على حسابك | `video.publish` + تدقيق تيك توك للتطبيق؛ وقبل التدقيق الخصوصية `SELF_ONLY` فقط |

ابدأ بـ `inbox`: يعطيك الأتمتة الكاملة حتى آخر خطوة، ويُبقي قرار النشر بيدك — وهو ما توصي به
قاعدة المراجعة البشرية في النظام أصلاً.

**الرموز:** رمز الوصول صالح ٢٤ ساعة ويُجدَّد تلقائياً من `refresh_token` (صالح سنة) ويُحفظ في
`config.yml`. في GitHub Actions لا يمكن حفظ التجديد، فحدّث سر `TIKTOK_REFRESH_TOKEN` إن انتهت صلاحيته.

## حدود لا تُتجاوز

- لا تنشر أكثر من الإيقاع المحدد في الاستراتيجية — الإغراق يقتل الوصول.
- لا ردود آلية ولا متابعة/إلغاء متابعة آلية — مخالفة لشروط المنصات.
- كل رقم في المحتوى يجب أن يكون في المصدر أو في `facts.yml`؛ ما عداه يُحذف.
- السوشيال ميديا مصدر اكتشاف لا مصدر توثيق (§18).
