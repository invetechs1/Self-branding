# نظام بناء العلامة الشخصية — Personal Brand Engine

نظام متكامل لبناء حضور قوي في السوشيال ميديا ومحركات البحث خلال 12 شهراً، لتموضعك كـ:

> **مهندس وخبير في إدارة المشاريع والتخطيط الاستراتيجي وإدارة الشركات — رائد أعمال يشارك تجربته الحقيقية بشفافية.**

## المبدأ الحاكم

النظام لا يسأل: *"ماذا ننشر اليوم؟"* بل:

> *"ماذا حدث في العالم اليوم ويجب أن يفهمه يحيى، وما الزاوية الفريدة التي يمكنه إضافتها،
> وكيف تقوّي هذه الرؤية سمعته وتصنع قيمة أعمال طويلة المدى؟"*

التموضع: **الهندسة × الأعمال × التقنية × الذكاء الاصطناعي × العقار** —
رائد أعمال يعرف الصناعات التقليدية من الداخل ويبني التقنية التي تحوّلها.
المواصفة الكاملة في [`profile/persona-spec.md`](profile/persona-spec.md).

## مبدأ الحقائق

**كل المحتوى يُبنى من ملف واحد: `profile/facts.yml`** — وهو سجل إنجازاتك وخبراتك الحقيقية.
النظام لا يخترع إنجازات؛ بل يأخذ الحقيقة ويرويها بأقوى صياغة ممكنة.
القصة الحقيقية المروية باحتراف تتفوق دائماً على القصة المفبركة، لأنها:
- تصمد أمام التحقق (الصحفيون والمستثمرون والعملاء يتحققون).
- تولّد محتوى لا ينضب (دروس فشل، كواليس، أرقام حقيقية).
- تبني ثقة تتحول إلى فرص عمل فعلية، وليس مجرد متابعين.

## مكونات النظام

| المجلد | الوظيفة |
|--------|---------|
| `profile/` | ملف الحقائق + الشخصية الرقمية (`persona.yml` للكود، `persona-spec.md` للبشر) |
| `strategy/` | استراتيجية العلامة، خارطة طريق 12 شهراً، خطة SEO، أدلة المنصات |
| `content/` | قوالب المحتوى (تغريدات، ريلز، تيك توك) + رزنامة النشر |
| `automation/` | محرك الاستخبارات: اكتشاف الأخبار وترتيبها → توليد المحتوى → النشر المجدول → التعلّم |
| `docs/` | المستند التقني للمطور (جداول القاعدة، الوكلاء، الخوارزميات، التكاملات) |
| `site/` | موقع شخصي محسّن لمحركات البحث (SEO) |
| `outreach/` | عدة العلاقات الإعلامية: قوالب مراسلة البودكاست والصحافة + سجل المتابعة |
| `analytics/` | لوحة القياس + تقارير الاستخبارات الأسبوعية + تقرير التعلّم |
| `.github/workflows/` | تشغيل النشر تلقائياً بجدولة يومية |

## دورة العمل اليومية

```
مصادر الأخبار → ترتيب بالملاءمة (0-100) → تجميع المكرر → التحقق من الحقائق
      → زاوية واحدة + رؤية يحيى → نسخة لكل منصة → وسم اعتماد (أخضر/أصفر/أحمر)
      → مراجعتك → نشر مجدول → قياس الأداء → تعلّم يعيد ضبط الترتيب
```

## البدء السريع

1. **عبّئ `profile/facts.yml`** بمعلوماتك الحقيقية (الخطوة الأهم — كل شيء يعتمد عليها).
2. راجع `profile/persona.yml`: خريطة الاهتمامات، الأوزان، العتبات، قواعد السلامة — كلها قابلة للتعديل.
3. اقرأ `strategy/01-brand-strategy.md` ثم `strategy/02-roadmap-12-months.md`.
4. جهّز مفاتيح الـ API (انظر `automation/README.md`).
5. شغّل:
   ```bash
   python automation/persona.py --self-test        # فحص منطق النظام (بلا مفاتيح)
   python automation/news_engine.py --discover     # اكتشاف وترتيب أخبار اليوم
   python automation/generate_posts.py --from-news # مسودات موسومة بمستوى الاعتماد
   ```
6. راجع `automation/queue/queue.csv`، غيّر `status` إلى `approved` لما يعجبك — والباقي `rejected`
   (الرفض ليس إهداراً: `feedback.py --learn` يتعلم منه).

## قاعدة ذهبية

النظام يجدول وينشر تلقائياً، لكن **المراجعة البشرية قبل النشر إلزامية في أول 3 أشهر** —
صوتك الشخصي هو المنتج، والأتمتة أداة وليست بديلاً عنك.
