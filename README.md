# نظام بناء العلامة الشخصية — Personal Brand Engine

نظام متكامل لبناء حضور قوي في السوشيال ميديا ومحركات البحث خلال 12 شهراً، لتموضعك كـ:

> **مهندس وخبير في إدارة المشاريع والتخطيط الاستراتيجي وإدارة الشركات — رائد أعمال يشارك تجربته الحقيقية بشفافية.**

## مبدأ النظام الأساسي

**كل المحتوى يُبنى من ملف واحد: `profile/facts.yml`** — وهو سجل إنجازاتك وخبراتك الحقيقية.
النظام لا يخترع إنجازات؛ بل يأخذ الحقيقة ويرويها بأقوى صياغة ممكنة.
القصة الحقيقية المروية باحتراف تتفوق دائماً على القصة المفبركة، لأنها:
- تصمد أمام التحقق (الصحفيون والمستثمرون والعملاء يتحققون).
- تولّد محتوى لا ينضب (دروس فشل، كواليس، أرقام حقيقية).
- تبني ثقة تتحول إلى فرص عمل فعلية، وليس مجرد متابعين.

## مكونات النظام

| المجلد | الوظيفة |
|--------|---------|
| `profile/` | ملف الحقائق — المصدر الوحيد لكل المحتوى |
| `strategy/` | استراتيجية العلامة، خارطة طريق 12 شهراً، خطة SEO، أدلة المنصات |
| `content/` | قوالب المحتوى (تغريدات، ريلز، تيك توك) + رزنامة النشر |
| `automation/` | توليد المحتوى بالذكاء الاصطناعي + النشر المجدول عبر الـ APIs الرسمية |
| `site/` | موقع شخصي محسّن لمحركات البحث (SEO) |
| `.github/workflows/` | تشغيل النشر تلقائياً بجدولة يومية |

## البدء السريع

1. **عبّئ `profile/facts.yml`** بمعلوماتك الحقيقية (الخطوة الأهم — كل شيء يعتمد عليها).
2. اقرأ `strategy/01-brand-strategy.md` ثم `strategy/02-roadmap-12-months.md`.
3. جهّز مفاتيح الـ API (انظر `automation/README.md`).
4. شغّل `python automation/generate_posts.py` لتوليد أسبوع محتوى، راجعه، ثم يُنشر تلقائياً.

## قاعدة ذهبية

النظام يجدول وينشر تلقائياً، لكن **المراجعة البشرية قبل النشر إلزامية في أول 3 أشهر** —
صوتك الشخصي هو المنتج، والأتمتة أداة وليست بديلاً عنك.
