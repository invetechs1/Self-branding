# قوالب سكربتات تيك توك وريلز (30–60 ثانية)

> البنية الثابتة: خطّاف (0–3 ث) → محتوى مركز (3–45 ث) → دعوة لفعل (آخر 5 ث).
> كل `{...}` يُملأ من حقائقك الفعلية.

## قالب 1: المشكلة والحل

```
[خطّاف — وجهك للكاميرا]
"{نسبة/إحصائية حقيقية} من {المشاريع/الشركات} تفشل بسبب سبب واحد يمكن تجنبه."

[المحتوى — نص على الشاشة يرافق الكلام]
"السبب: {المشكلة}.
شفت هذا بنفسي لما {موقف حقيقي من تجربتك}.
الحل بثلاث خطوات:
1) {خطوة}  2) {خطوة}  3) {خطوة}"

[الخاتمة]
"أشرح {تخصصك} بلغة بسيطة يومياً — تابعني."
```

## قالب 2: القصة الشخصية (الأقوى في بناء الارتباط)

```
[خطّاف]
"في {سنة}، {موقف حقيقي صعب: خسارة/رفض/تعثر}."

[القصة — قوس سردي: المحاولة ← الفشل ← الدرس ← النتيجة الحالية]
"{تفاصيل موجزة صادقة بالأرقام الحقيقية}"

[الخاتمة]
"الدرس: {خلاصة عملية}. احفظ الفيديو إذا كنت تبني مشروعك."
```

## قالب 3: الأداة/الإطار في دقيقة

```
[خطّاف]
"أداة يستخدمها مدراء المشاريع المحترفون وأغلب الناس ما سمعوا عنها."

[شرح مرئي — شاشة/سبورة/جرافيك]
"{اسم الأداة/الإطار} — تستخدمها كذا: {شرح تطبيقي بمثال}"

[الخاتمة]
"جرّبها هالأسبوع وقلي النتيجة في التعليقات."
```

## قالب 4: الرد على سؤال متابع

```
[خطّاف — لقطة على تعليق حقيقي]
"سألني {متابع}: {السؤال}"
[إجابة عملية مختصرة]
[دعوة: "اسألني في التعليقات وأجاوب بفيديو"]
```

## قواعد الإنتاج

- ترجمة نصية (captions) في كل فيديو — أغلب المشاهدة بدون صوت.
- إضاءة طبيعية + صوت نقي أهم من جودة الكاميرا.
- صوّر 4–5 فيديوهات في جلسة واحدة أسبوعياً (batching) — الاستمرارية تنكسر بدون هذا.
- انشر نفس الفيديو على تيك توك وريلز انستقرام ويوتيوب شورتس.
