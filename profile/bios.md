# نِبَذ المنصات (Bios) — نسخة موحدة معدّلة لكل منصة

> تُملأ من `facts.yml`. القاعدة: من أنت + ماذا يستفيد المتابع + إثبات واحد حقيقي + دعوة.
> نفس الصورة الشخصية الاحترافية ونفس الاسم في كل المنصات — الاتساق شرط بناء الكيان في Google.

## X / تويتر (160 حرفاً)

```
{لقبك الحقيقي: مهندس / PMP®}
أشارك يومياً أدوات عملية في إدارة المشاريع وبناء الأعمال — من التجربة وبالأرقام.
{رابط الموقع}
```

## انستقرام (150 حرفاً — أسطر قصيرة)

```
{الاسم} | {اللقب الحقيقي}
📊 إدارة مشاريع وتخطيط استراتيجي ببساطة
🎯 {إثبات حقيقي واحد: سنوات خبرة / شهادة / مشروع}
👇 أقوى محتواي هنا
{رابط}
```

## تيك توك (80 حرفاً)

```
{اللقب} | أشرح إدارة المشاريع وبناء الأعمال بلغة الناس
```

## لينكدإن (Headline — 220 حرفاً)

```
{اللقب الحقيقي} | أساعد {الجمهور: الشركات الناشئة والفرق} على {نتيجة: تخطيط وتنفيذ مشاريعها}
| {أقوى إثباتين حقيقيين من facts.yml}
```

## قسم "About" في لينكدإن (فقرة سردية)

```
{افتتاحية: مشكلة يعيشها جمهورك}.
خلال {س} سنوات في {مجالك}: {2–3 إنجازات حقيقية بالأرقام من facts.yml}.
اليوم أشارك ما تعلمته — الأدوات، الأخطاء، والأرقام — حتى تصل أسرع مما وصلت.
أكتب أسبوعياً عن: {أعمدة المحتوى}. تواصل معي بخصوص: {استشارات / تعاون / ضيافة بودكاست}.
```

## ملاحظات

- حدّث الإثباتات كل 3 أشهر مع نمو إنجازاتك الحقيقية — النبذة كائن حي.
- الرابط في كل النِبَذ يذهب لموقعك (أو صفحة روابط داخل موقعك أنت من يملكها، وليس linktree).
